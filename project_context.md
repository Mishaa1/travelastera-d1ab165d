# ASTERA – Project Context

## Mission

ASTERA is an AI-powered travel operating system.

We are NOT another itinerary planner.

Most travel websites ask users to choose a destination first.

ASTERA starts with:

- Budget
- Dates
- Departure city
- Travel style
- Interests
- Preferences

It then discovers and optimizes the best journeys automatically.

Our promise:

> See how far your budget can take you.

---

# Product Philosophy

Every feature should answer one question:

"Does this reduce decision fatigue?"

Users should never feel overwhelmed.

ASTERA should replace dozens of travel tabs with one intelligent recommendation.

# APIs

Duffel

Maps:
MapLibre

Weather:
Open-Meteo

Architecture should use provider abstractions.

# AI Coding Rules

Before implementing any feature:

1. Read this file.

2. Preserve ASTERA's design language.

3. Preserve the premium aesthetic.

4. Do not introduce generic travel website patterns.

5. Keep components reusable.

6. Explain major architectural decisions.

7. Minimize technical debt.
